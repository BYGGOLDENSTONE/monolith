# UI authoring ve çalışma zamanı doğrulaması — 6 Eylül 2026

[Kanonik çalışma ve temizlik raporu](../COMPLETION_2026_09_06.md). Test hedefi RecycleCo, UE 5.7.4. Editor build 4, üretilen `UCompletionKeySettings` C++ sınıfı dahil başarıyla derlendi.

## Tamamlanan davranışlar

- `build_menu_from_spec`: tüm istek için ön doğrulama; embedded spec veya main_menu/pause_menu/settings_panel başlangıç düzeni; gerçek CommonUI stack host'u, desired-focus override'ı ve isimle kalıcı explicit navigation. Stack'ler Slate hazır olduktan sonra Construct sırasında temizlenip doldurulur.
- `apply_token_binding`: bir string/name alan ve setter türünde değer döndüren static BlueprintPure resolver için gerçek Construct graph'ı. Önceki Construct akışı korunur; tekrar binding ve geçersiz resolver mutasyon öncesinde reddedilir.
- Settings scaffold: yerel oyuncunun Enhanced Input ayarlarını kaydeden/yükleyen gerçek C++ kodu; mevcut aktif settings instance'ı ve kayıtlı IMC'ler korunur. Public `UEnhancedPlayerInput::GetUserSettingsSaveFileName()` kullanılır. Kaynak dosyası çifti çakışması ve geçersiz identifier yazımdan önce reddedilir.
